Cara Pasang Fail APK

Aplikasi di gedung ini diedarkan secara terus tanpa Play Store rasmi Google. Ikuti langkah mudah ini untuk memasang APK di telefon Android anda:

Langkah 1

Muat Turun APK

Tekan butang "Muat Turun" pada mana-mana app pilihan anda.

Langkah 2

Buka Notifikasi

Ketik pada notifikasi muat turun selesai atau cari fail di folder 'Downloads'.

Langkah 3

Luluskan Sumber

Jika amaran "Install Unknown Apps" muncul, tekan Settings -> Allow from this source.

Langkah 4

Tekan Pasang

Tekan butang Install dan tunggu beberapa saat sehingga selesai!

    Panduan Memasang APK di Android

    Android mengutamakan keselamatan dengan menyekat fail luar Google Play secara lalai. Ikuti panduan mengikut jenama telefon anda di bawah:

    📱 Telefon Samsung (One UI)

    1. Bila muat turun selesai, ketik fail APK.
    2. Bila pop-up "Chrome / File Manager needs permission" keluar, tekan Settings.
    3. Hidupkan suis "Allow from this source" dan tekan Install.

    📱 Telefon Xiaomi / Redmi / POCO (HyperOS / MIUI)

    1. Ketik fail APK yang dimuat turun.
    2. Akan ada skrin amaran keselamatan 10 saat.
    3. Tandakan kotak "I am aware of possible risks" dan tekan OK -> Install.

    📱 Telefon Vivo / iQOO / Oppo / Realme

    1. Buka fail dari bar notifikasi.
    2. Masukkan kata laluan / cap jari telefon jika diminta untuk mengesahkan pemasangan.
    3. Tekan "Install anyway" atau "Benarkan Pemasangan".
